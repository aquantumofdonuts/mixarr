# Mixarr v2.1.4

**Release Date:** 2026-03-30  
**Type:** Hotfix patch

## Summary

Hotfix for the v2.1.3 slim image build failure. Same root cause as v2.1.3 — missed in `docker/Dockerfile.slim`.

## Bug Fixes

### Slim Image Build Failure
`docker/Dockerfile.slim` had the same broken `COPY` instruction as `Dockerfile.unified`:

```dockerfile
# BROKEN - this path doesn't exist
COPY --from=prod-deps --chown=node:node /app/apps/api/node_modules /app/api/node_modules
```

npm workspaces hoists all dependencies to the root `/app/node_modules`. This path never exists, causing the slim build to fail with:
```
ERROR: failed to compute cache key: "/app/apps/api/node_modules": not found
```

## Upgrade Notes

No database migrations or configuration changes required. Standard Docker image update.
