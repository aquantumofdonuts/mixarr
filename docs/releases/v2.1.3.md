# Mixarr v2.1.3

**Release Date:** 2026-03-30  
**Type:** Hotfix patch

## Summary

Hotfix for the v2.1.2 Docker build failure that prevented the image from being published.

## Bug Fixes

### Docker Build Failure
The `docker/Dockerfile.unified` had a broken `COPY` instruction that referenced a path which does not exist in the build stage:

```dockerfile
# BROKEN - this path doesn't exist
COPY --from=builder-api /app/apps/api/node_modules /app/api/node_modules
```

npm workspaces hoists all dependencies to the root `/app/node_modules`. The path `/app/apps/api/node_modules` never exists in the builder, causing:
```
ERROR: failed to build: failed to solve: failed to compute cache key: "/app/apps/api/node_modules": not found
```

The correct single-line COPY is retained:
```dockerfile
COPY --from=builder-api /app/node_modules /app/api/node_modules
```

### CI `latest` Tag Not Published
After the v2.1.2 workflow trigger was changed from `release: published` events to `push: tags`, the condition for applying the `latest` Docker tag was not updated. It still checked `github.event_name == 'release'` which would never be true under the new trigger. Updated to `startsWith(github.ref, 'refs/tags/v') && !contains(github.ref, '-')`.

## Upgrade Notes

No database migrations or configuration changes required. Standard Docker image update.
